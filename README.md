# Dama Royale

Jogo de damas brasileiras em HTML, CSS e JavaScript, com interface responsiva e modo de treino contra uma IA local.

## Como testar

Abra [https://guto157.github.io/dama-royale/](https://guto157.github.io/dama-royale/) depois de ativar o GitHub Pages.

Para ativar: no GitHub, entre em **Settings → Pages**, escolha **Deploy from a branch**, selecione **main** e a pasta **/ (root)** e salve.

## O que já está nesta versão

- Tabuleiro 8×8.
- Peças comuns e damas voadoras.
- Captura obrigatória, inclusive para trás.
- Sequências de captura e prioridade para a maior quantidade de peças.
- Promoção a dama.
- Três níveis de dificuldade da IA.
- Interface adaptada para celular.
